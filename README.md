# İşler Güçler

Kişisel hatırlatıcı uygulaması: Acil Merkez, İşler (Dergi, Kitap, Tasarım, Diğer), Unutma ve Fikir Defteri.

Telefonda Safari'den açıp **Paylaş → Ana Ekrana Ekle** ile uygulama gibi kullanılır.

- Veriler yalnızca telefonda saklanır. Bu depoda kişisel veri yoktur.
- Yedek almak için uygulamada sağ üstteki ok → **Yedek al**.
- iPhone Anımsatıcılar bağlantısı için uygulamada sağ üstteki ok → **Anımsatıcılar**.
